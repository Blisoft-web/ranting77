Pre-Press Standard

Checklist Format File Sebelum Cetak

Patuhi panduan teknis ini untuk memastikan kelancaran alur produksi dan hasil cetak optimal.

1. Format File

PDF X-1a:2001, TIFF, atau AI/EPS dengan font yang sudah di-*Create Outlines*.

2. Color Mode

Wajib mode **CMYK**. File bertipe RGB akan otomatis tersimulasi ke CMYK mesin.

3. Resolusi & Skala

Minimal **300 DPI** untuk cetak A3+/Offset. Gambar outdoor skala 1:1 minimal 150 DPI.

4. Area Bleed

Sediakan *bleed* minimal 2 mm di luar area potong untuk mencegah garis putih terpotong.
