Panduan Format File (Cetak Bebas Masalah)

1. Format Dokumen Utama

Gunakan format **PDF (Press Quality), TIFF, atau PNG High-Res**. Hindari screenshot atau file Microsoft Word jika ada layout presisi.

2. Mode Warna CMYK

Pastikan warna dokumen diset ke **CMYK**, bukan RGB. Format RGB dari HP/Layar komputer bisa mengalami pergeseran warna saat dicetak.

3. Resolusi Minimal 300 DPI

Untuk hasil gambar tajam dan tidak pecah, gunakan file beresolusi minimal **300 DPI** pada skala ukuran cetak asli (1:1).

4. Berikan Jarak Potong (Bleed)

Tambahkan jarak aman / bleed minimal **2 mm** di sekeliling desain agar teks penting tidak terpotong mesin *guillotine*.
